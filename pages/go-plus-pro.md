## 免费版和 Plus 的区别

免费版能不限次数地文字聊天，但带上传、图像、语音、深度研究的消息都有上限，碰到上限后要等重置。

Plus 相比免费版多了这些，都是官方帮助中心列出的：

- **高流量时段优先访问**，高峰期不容易被中断。
- **更高的模型限额**，可用的模型选项更多。
- **高级推理访问权限**，适合写代码、做规划和多步骤分析。
- **更快的响应速度**。
- **项目、计划任务和自定义 GPT**。
- **更高的 Codex 使用量**。

官方月费是 20 美元，只能按月付，不支持年付。订阅不包含 API 用量。

判断要不要升 Plus，看一件事：你是不是每周都会被限额打断。偶尔碰到一次不用升，几乎每天都碰到就值得。

## Go 和 Plus 的区别

Go 是低价套餐，面向所有支持 ChatGPT 的国家和地区开放。它在免费版基础上提高了图像生成、文件上传、数据分析的额度，记忆也更长。

Go 和 Plus 的差距主要在三处：

1. **模型。** Go 的推理用的是 GPT-5.6 Luna，官方明确 Go 不含 GPT-5.6 Sol，也不提供旧版模型。Plus 有包括 GPT-6 在内的高级推理模型。
2. **高级功能。** 官方写明部分高级产品和更高层级的功能需要 Plus 或其他符合条件的套餐。Plus 有增强版深度研究和更高的 Codex 用量。
3. **广告。** 官方定价页注明 Go 套餐可能包含广告，并说明正在特定地区对符合条件的 Go 用户进行广告测试。

Go 的语音模式使用限制和免费版相同。如果你主要是嫌免费版的图片和文件额度不够，Go 能解决；如果要的是更强的模型和 Codex，直接上 Plus。

## Plus 和 Pro 的区别

Pro 包含 Plus 的全部内容，官方定价页列出的新增项是：

- 3 档用量可选（Pro 100、Pro 200、Pro 500）
- 由 GPT-6 Astra 驱动的 Pro 推理
- 更长的 Codex 和 ChatGPT 工作会话
- 全天候智能体 dot
- 更快速、无限量的图像创作
- 最高深度研究用量
- 最大记忆与上下文容量
- 更多项目、任务和自定义 GPT
- 新功能研究预览

对多数人来说，Plus 和 Pro 的实际差别就是**用量**。Plus 的模型和工具已经能完成同样类型的任务，Pro 让你在更长时间里不碰到上限。

所以判断标准很简单：Plus 没用到上限，升 Pro 没有意义；每周都用完，升 Pro 100 起步。

## 常见问题 FAQ

### Q：ChatGPT Plus 和普通版差别大吗？

差别主要在额度和模型。免费版文字聊天不限次数，但上传、图像、语音和深度研究都有上限；Plus 的限额更高，有高级推理模型、项目和计划任务，Codex 用量也更高。每周都被限额打断的人会明显感到差别。

### Q：ChatGPT Go 值得买吗？

如果只是嫌免费版的图像和文件额度不够，Go 能解决。但 Go 不含 GPT-5.6 Sol，官方注明可能包含广告，部分高级功能仍需要 Plus。想用更强的模型和 Codex，建议直接选 Plus。

### Q：Plus 升 Pro 之后，原来的 Plus 怎么算？

在官网更改套餐按官方的计费规则处理。在 OKAI66 充值升级是覆盖，新套餐从升级当天重新算一个月，原 Plus 剩余天数不会叠加或折算，所以建议快到期时再升。

### Q：Plus 每天有次数限制吗？

有使用限制，但官方没有在定价页公布固定数字，并说明限制会根据系统状况变化。达到某个模型的上限后，这个模型会暂时不可用，等用量重置或换其他模型即可。

### Q：ChatGPT 订阅包含 API 吗？

不包含。Plus、Go、Pro 的订阅和 API 用量是分开计费的，用 API Key 要另外按量付费。
